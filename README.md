Библиотека для логирования.

Лог состоит из уровня важности(ERROR/WARNING/INFO), текста лога и времени.

Библиотека принимает имя текстового файла и минимальный уровень важности.
После этого можно добавлять логи для каждого отдельно файла и она будет записывать
их в файлы параллельно, не мешая работать с другими файлами.

Можно добавлять логи только с текстом (уровень важности будет минимальным автоматически, а время текущее, на моент добавления), а можно и с уровнем, и со временем.

Также реализована тестовая программа для проверки работы библиотеки.

-LogLib
Сама библотека и все сопутсвующие файлы для её реализации.

-TestApp
Тестовая программа

Собрать проект можно через Makefile или CMakeLists.txt
Makefile:
    make all
CMakeLists.txt:
    cd build
    cmake ..
    cmake --build .

Запуск тестовой программы:
    cd build
    ./TestLogLib
